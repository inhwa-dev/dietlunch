# DietLunch — 발표용 통합본

자바 콘솔 기반 다이어트 도시락 추천 및 식단 스케줄링 프로젝트입니다.

## 실행 환경
- JDK 8 이상 (Java 8+)
- Windows: `run.bat` 실행
- 터미널에서 직접 실행:
  ```sh
  javac -encoding UTF-8 -d out -sourcepath src/main/java src/main/java/com/project/Main.java
  java -cp out com.project.Main
  ```
- 실행 진입점: `com.project.Main`
- `src/main/java` 아래가 **통합본**입니다. `src/service`는 이전 작업 파일이므로 함께 컴파일하지 마세요.

## 기능 흐름
1. 회원가입: ID, 비밀번호, 키, 몸무게, 목표(BULK/DIET/KEEP), 하루 목표 칼로리 입력
2. 로그인
3. 목표/칼로리/영양비율 기준 도시락 추천 (엄격한 조건에서 추천 결과가 없으면 목표/칼로리 기준으로 단계적 대체 추천)
4. 선택한 목표로 N일 식단 스케줄 출력 (세 메뉴를 아침·점심·저녁에 순환 배치)
5. **테스트용** 결제: 가상 잔액을 입력받아 8,600원 차감, 다음 결제일 표시

## 시연 예시
- 회원가입: `demo`, 비밀번호 `1234`, 키 `175`, 몸무게 `70`, 목표 `DIET`, 칼로리 `1500`
- 로그인: `demo` / `1234`
- 추천 출력 확인
- 식단 생성: `1` -> `3`일
- 결제: `1` -> 가상 잔액 `20000`원
- 예상 결제 후 잔액: `11400`원

## 발표 시 주의할 점
- 실제 PG사와 연동한 카드 결제가 아닙니다. 가상의 잔액으로 시연하는 결제 로직입니다.
- 계정과 구독 정보는 프로그램 메모리에서만 관리하므로 종료 후 유지되지 않습니다.
- 등록 도시락은 벌크업/다이어트/유지 각 3종씩, 총 9종입니다.
- 숫자 입력 위치에 문자를 넣으면 예외가 날 수 있으니 시연 때 메뉴 번호 및 수치를 입력해 주세요.
- Java 8 호환 switch 문으로 수정했습니다.

## 핵심 소스
- `Main.java`: 전체 사용자 시나리오와 메뉴 흐름
- `MemberService.java`: 회원가입/로그인
- `MatchService.java`: 맞춤 식단 추천
- `MealPlanSystem.java`: 식단 데이터 9종
- `MealScheduler.java`: 날짜별 아침/점심/저녁 스케줄
- `Payment_Information.java`: 가상 결제·구독 관리

## 확인 사항
본 브랜치는 원본 `main`을 보존한 발표 대비 수정본입니다. GitHub 환경에서 원격 실제 컴파일/대화형 입력 실행까지 검증한 것은 아니므로, 발표용 컴퓨터에서 `run.bat`와 위 시나리오를 한 번 실행해 확인하세요.

## JDK가 없을 때: 오프라인 브라우저 시연
- 압축 해제 후 `presentation-demo.html`을 **더블클릭**하면 Chrome/Edge 등 브라우저에서 동작합니다.
- 인터넷이나 자바 설치가 필요 없는 **별도 기능 재현 데모**이며, Java 소스코드를 실행하는 것이 아닙니다.
- Java 실제 실행은 `run.bat`(JDK 8 이상 필요)로 검증하세요.
- 발표 전에 양쪽 모두 미리 열어 직접 테스트하는 것을 권장합니다.
